# Campaign Compass
An email campaign dashboard: enter your numbers, see the funnel, compare campaigns and check whether an A/B result is real or just noise.

**The starter campaigns are sample data, not real client results.** Replace them with your own or reset from the header. Data is saved in your browser only.

## Rates used
Open rate = opens / sent. Click rate = clicks / sent. Click-to-open = clicks / opens. Conversion rate = conversions / clicks.
The A/B check uses a two-sided two-proportion z-test.

## Run
`npm install` then `npm run dev`. Build with `npm run build`. Deploy to Vercel or run `npm run deploy` for GitHub Pages.
