# Campaign Compass — Redesigned

Polished React/Vite portfolio project for campaign planning and tracking.

## Features
- Responsive marketing workspace dashboard
- Campaign search and filters
- New campaign creation
- Campaign detail modal
- Status updates
- LocalStorage persistence
- Mobile-friendly layout

## Run
npm install
npm run dev

## Build
npm run build

## Vercel
Upload/push the project and Vercel will detect Vite automatically.
